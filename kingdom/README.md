# 小小王国守卫战

一个竖屏安卓小游戏：白天驾着国王四处走，站上虚线格子投金币建造箭塔、城墙、房屋、兵营；夜晚敌人沿土路进攻城堡，守住越多夜越强。

## 下载安装
每次推送到 `main`，GitHub Actions 会自动打包并发布到 **Releases**：打开仓库右侧的 Releases → 最新的 `kingdom-N` → 下载 `KingdomGuard.apk` 安装即可（首次需允许"安装未知来源应用"）。

## 玩法
- 按住屏幕任意位置拖动 = 摇杆，移动国王
- 站在格子上自动投入金币，投满即建成；站在建筑上可继续升级（最高 3 级）
- 箭塔自动射击；城墙挡路；兵营派出士兵；房屋天亮时产金币；升级城堡会提升城堡血量、国王攻击和生命，并让城堡也能射击
- 国王自动挥剑，击败敌人掉落金币，靠近自动吸取
- 第 2、3 夜会开放新的进攻路线，每 5 夜出现首领

代码在 `kingdom/src/main/java/com/example/kingdom/`，纯 Java + Canvas 绘制，无第三方依赖。
