# 后续功能分组

骨架已经有：中文描述 → AI 写正负面提示词（可改、实时显示、格式不对自动重试）→ NAI 出图 → 图库（大图、配方、存相册、用这套重画、删除），设置页（AI 接口、NAI 参数、质量词/负面词默认值和恢复、画师串、自然语言开关、规范可改），测试连接时显示 Anlas 余额。

剩下的按「各自改哪些文件」分成 8 组。同一轮里的组改的文件不重叠，可以分开同时做；后一轮依赖前一轮。

## 第一轮（互不冲突，可以同时开）

| 组 | 内容 | 主要改的文件 |
| --- | --- | --- |
| A 出图参数 + 画风（✅ 已完成） | 加 V4 / V3 模型；尺寸预设下拉 + 自定义；锁定种子按钮；Anlas 余额常驻显示、出图后自动刷新；画师串 / 风格模板（前缀、后缀、负面）多套保存、下拉一键切换 | `参数.js`、`出图.js`、`页面-设置.js` 的 NAI 页、新 `风格.js` |
| B 队列 | 并发数可调；NAI 限流（429）自动等待重试；一次出多张；生成中随时取消；重绘同一张 | `队列.js`、`页面-创作.js` 里出图按钮那一段 |
| G 图库增强 | 大图左右滑动、双指缩放、长按保存；PNG 自动转存 JPG；图片显示大小四档 | `图库.js`、`页面-图库.js` |
| I 其他 | 设置导出 / 导入；应用内检查更新（看 Releases 里最新的 shengtu-*） | 新 `备份.js`、`更新.js`（用 `SettingsPage.addTab`） |
| D 标签库（已完成） | 2 万多个 Danbooru 标签，按热度排序、可搜索，**英文左边加一列中文**；点一下插进正面提示词；AI 写完后对照标签库纠错 | 新 `标签库.js`、新数据文件 `依赖/标签.json`（用 `Writer.addContext`） |

## 第二轮（要等 A 改完 `出图.js`）

| 组 | 内容 | 主要改的文件 |
| --- | --- | --- |
| C 多角色 + Vibe | 每个角色单独的正面 / 负面提示词（NAI 的 Character Prompts）；Vibe Transfer 画风参考，强度、信息提取量，导入导出 `.naiv4vibe` | 新 `多角色.js`、`参考图.js`（用 `Nai.addHook`），创作页加角色区 |
| E 角色库 | 存角色固定外貌，提示词里写名字自动换成外貌标签；AI 给新角色自动建档，永久变化（染发、剪发）自动更新；全局角色（玩家等），AI 不改 | 新 `角色库.js`（用 `Writer.addContext`），`写词.js` 的 JSON 格式加 `characters` / `changes` |

## 第三轮（要等 C、E 定好 JSON 格式）

| 组 | 内容 | 主要改的文件 |
| --- | --- | --- |
| H AI 进阶 + 批量 | 一段描述规划多张图（按画面节奏拆开出）；AI 重写提示词，可附一句要求（如「表情再害羞一点」）；破限 / 生图规范 / 思维链分开可改；导入酒馆预设拼消息（搬问答机的 `预设.js`）；批量页：一次排很多条描述，挨个写提示词并出图 | `写词.js`、`页面-创作.js`、新 `页面-批量.js`、新 `预设.js` |

## 注意

- 每组做完都在这个 App 里跑 `测试/网页测试.js`，再加自己那组的测试。
- 改 `页面-创作.js` 的组（B、C、H）尽量只动自己那一块，或者错开时间做。
- 每一组都能单独出一个新版 APK 给你试用，不用等全部做完。
