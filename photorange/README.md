# 照片按月复制（安卓）

按文件名里的日期挑照片：选「从 某年某月 到 某年某月」，把这段时间拍的照片**复制**到指定文件夹，或直接**上传到百度网盘**，原图不动。
纯 Java 原生应用，无第三方依赖。

## 下载安装
推送后 GitHub Actions 自动打包并发到 **Releases**：打开仓库 Releases → 最新的 `photorange-N` → 下载 `照片按月复制.apk`。
签名固定，新版本可以直接覆盖安装，设置保留。

## 用法
1. 第一次打开会自动跳到「所有文件访问权限」页面，把开关打开再返回（Android 10 及以下弹普通存储权限）。
2. 顶部「照片在」：默认 `内部存储/DCIM/Camera`，点「更换」改。扫描完显示总数。
3. 时间轴面板：每根柱子是一个月，高度是那个月的张数。点一个月设为起点，再点另一个月设为终点；
   也可以用下面的「从 / 到」年月下拉，或「全部 / 今年 / 去年」。面板顶上实时显示范围和张数、大小。
4. 「复制到」：选目标文件夹（可在选择框里新建），可开「按年月分到子文件夹」（`2014-11/`、`2014-12/`…），点「复制 N 张照片」。有进度条、可取消，复制完自动通知相册刷新。
5. 「上传 N 张照片到百度网盘」：不复制，一次把范围内的照片全部交给百度网盘 App，在网盘里选上传到哪个文件夹。
   - 一次最多交 1500 个（系统跨 App 传递有大小上限），超过才自动分批。
   - 网盘那边一次吃不下时点「分批发送」：每批 100/200/500/1500 可切换，点一批 → 网盘里选位置 → 回来点下一批，发过的打 ✓。
   - 没装百度网盘时退回系统分享面板。
6. 底部「扫描选项」：包含子文件夹、包含视频、文件名没日期的按修改时间算。

## 界面
蓝晒照片的配色：普鲁士蓝底、相纸白字，只有选中的时间段和主按钮用日光黄（颜色都在 `Ui.java`，弹窗主题在 `res/values/themes.xml`）。
整页只有时间轴一块面板，其余是直接排在底色上的行。全部用代码搭界面，没有布局 xml。

## 规则
- 认文件名里的 `YYYYMMDD`（也认 `YYYY-MM-DD`、`YYYY_MM_DD`），前后不能紧挨别的数字：
  `IMG_20141114_164041.jpg`、`VID_…mp4`、`PANO_…`、`MVIMG_…`、`IMG_20141114_164041_1.jpg`、`Screenshot_2016-01-01-…png` 都行；
  `mmexport1415954841000.jpg` 这种毫秒时间戳不认（可勾「按修改时间算」兜底）。
- 目标里已有同名同大小 → 跳过（重复跑不会重复复制）；同名不同大小 → 另存为 `名字 (1).jpg`。
- 先写 `.part` 临时文件再改名，取消或出错不会留下半截照片；保留原文件修改时间。
- 目标文件夹在源文件夹里面时，扫描会自动跳过它。

## 代码
`photorange/src/main/java/com/example/photorange/`
- `MainActivity.java`：界面、权限、扫描/复制/上传调度
- `Ui.java`：配色和按钮、药丸、开关行等小部件
- `TimelineView.java`：按月柱状时间轴（自绘，点选起止月）
- `PhotoScanner.java`：扫描文件夹、从文件名解析年月（纯 Java，可在电脑上直接测）
- `Copier.java`：复制、去重、改名（纯 Java）
- `FolderPicker.java`：文件夹选择框
- `ShareProvider.java`：把照片以 content:// 只读地交给百度网盘。地址很短（`content://photorange/<第几次>/<第几个>`），一次才能交出上千个；每次的文件清单存在应用私有目录，App 被回收后网盘照样能读

本地编译检查：仓库外放一份 `android.jar`（如 Sable/android-platforms 的 android-34），`javac -cp android.jar -d /tmp/out photorange/src/main/java/com/example/photorange/*.java`。
