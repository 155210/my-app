# 小说翻译（安卓版）

把长篇小说 TXT 按长度切块，调用你自己的大模型接口并发翻译，导出带目录的 EPUB / TXT。
原生安卓应用（纯 Java，无第三方依赖），不是网页套壳。

## 下载安装
每次推送到 `main`，GitHub Actions 会自动打包并发布到 **Releases**：打开仓库右侧的 Releases → 最新的 `translator-N` → 下载 `NovelTranslate.apk` 安装（首次需允许"安装未知来源应用"）。
签名固定，以后的新版本可以直接覆盖安装，翻译进度不会丢。

## 功能
- **接口**：OpenAI 兼容（DeepSeek、各类中转、局域网本地模型）/ Gemini / Anthropic，拉取模型列表、快速测试；原生请求没有 CORS 限制
- **流式输出**：实时显示正在翻的那一块；「无响应超时」= 多久没收到新内容就重试
- **后台翻译**：前台服务 + 通知栏进度，切后台、锁屏继续跑
- **分块**：一律按 token 上限切；可「重新分块」；「强制记忆块为章节」开关只影响提示词
- **分块列表**：每块显示 token 数；点开可查看/编辑原文译文、复制、并入上下块、按上限重切、单独重翻、删除
- **起始块 / 多选**：从指定块开始跑；全选、反选、选失败块，批量重翻或删除
- **导入更新章节**：仅新增 / 完整文件两种模式，已翻译的块不动
- **术语表**：只把本块出现过的术语带进请求；AI 可自动补充新术语
- **导出**：EPUB（mimetype 不压缩、带目录）和 TXT；导出时用章节正则在译文里重新划分章节，默认正则同时认 第X话/章/节/回；可先「测译文」「预览目录」
- **备份**：任务（原文+译文+术语）和配置（可选是否含 Key）的 json 与网页版互通

代码在 `translator/src/main/java/com/example/noveltranslate/`。
